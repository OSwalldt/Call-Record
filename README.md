# Запись звонка

Веб-приложение для быстрого оформления и ведения записей телефонных обращений.

## Возможности

- Заполнение данных: организация, имя, номер телефона и суть проблемы.
- Копирование отдельных полей и всей заявки целиком.
- Сохранение заявок в историю.
- Редактирование и удаление сохранённых заявок.
- Локальное хранение данных в браузере (`localStorage`).
- Отметка заявок как выполненных с автоматической фиксацией даты и времени завершения.
- Автоматический расчёт времени между созданием и завершением заявки.
- Отображение времени создания, завершения и затраченной продолжительности в истории заявок.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

Каждый пользователь работает со своей независимой историей заявок.

## Запуск приложения

**Вариант 1. Через GitHub Pages**

1. Открыть приложение в браузере: [https://oswalldt.github.io/Call-Record/](https://oswalldt.github.io/Call-Record/)
2. Начать работу без установки дополнительных программ.

**Вариант 2. Локальный запуск**

1. Скачать файлы `index.html` и `favicon_v10.svg` из репозитория.
2. Сохранить оба файла в одной папке на компьютере.
3. Открыть `index.html` двойным щелчком мыши.
4. Начать работу в браузере.

Дополнительные программы и сервер не требуются.

## Хранение данных

Заявки сохраняются в локальном хранилище браузера (`localStorage`).

- Хранить данные в браузере и на устройстве, где они были сохранены.
- Использовать отдельную историю для каждого пользователя.
- Сохранять статус выполнения заявки и отметку об учёте времени.
- Учитывать, что очистка данных браузера может привести к удалению истории заявок.

## Обновление приложения

1. Подготовить обновлённые файлы приложения.
2. Заменить файл `index.html` в корне репозитория.
3. Добавить или обновить файл иконки `favicon_v10.svg` в корне репозитория.
4. Сохранить изменения через `Commit changes`.
5. Дождаться завершения публикации GitHub Pages.
6. При необходимости обновить страницу сочетанием клавиш `Ctrl + F5`.
